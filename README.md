# 📊 Análise de Salários e Tendências na Área de Ciência de Dados

## 📌 Visão Geral

Este projeto foi desenvolvido durante o curso de **Inteligência e Análise de Dados** do **SENAI Suíço-Brasileiro**, com o objetivo de aplicar técnicas de **Análise Exploratória de Dados (EDA)** para investigar tendências salariais, perfis profissionais e características do mercado global de Ciência de Dados.

A partir de um conjunto de dados contendo milhares de registros reais de profissionais da área, foram realizadas etapas de limpeza, transformação, análise estatística e visualização de dados para identificar padrões relevantes e gerar insights sobre o mercado de trabalho.

Além da análise geral, foi desenvolvido um estudo específico sobre o segmento de **Machine Learning e Inteligência Artificial**, uma das áreas mais promissoras e estratégicas da tecnologia atualmente.

---

## 🎯 Objetivos do Projeto

* Aplicar técnicas de Análise Exploratória de Dados (EDA);
* Realizar limpeza e tratamento de dados reais;
* Investigar tendências salariais na área de dados;
* Comparar cargos, níveis de experiência e modelos de trabalho;
* Analisar a evolução do mercado entre 2020 e 2023;
* Explorar o crescimento da área de Machine Learning e Inteligência Artificial;
* Desenvolver visualizações para apoiar a tomada de decisão baseada em dados.

## 📋 Etapas do Projeto

### 1. Entendimento dos Dados

* Inspeção inicial do dataset
* Identificação dos tipos de variáveis
* Compreensão do contexto dos dados

### 2. Limpeza e Preparação

* Verificação de valores nulos
* Identificação de registros duplicados
* Remoção de inconsistências
* Padronização e tradução das variáveis

### 3. Análise Exploratória

* Estatísticas descritivas
* Distribuição salarial
* Evolução temporal dos salários
* Comparação entre categorias profissionais
* Análise de senioridade

### 4. Análise Focada em Machine Learning e IA

* Distribuição geográfica das vagas
* Perfil das empresas contratantes
* Crescimento da demanda ao longo do tempo
* Relação entre senioridade e remuneração
